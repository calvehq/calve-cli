# general-project

A change workflow with no source code: an Intent and Task produce a ChangePack that sets
structured notes, a checklist and a key/value record through the `org.calve.general`
extension. The pack requires review, is approved, qualified and promoted, and the accepted
values are then read back from the active Baseline.

```sh
CALVE=target/debug/calve examples/general-project/run.sh
```
