# Security policy

Calve is pre-release. No stable release line has a support window yet.

Please report security vulnerabilities through GitHub private vulnerability reporting for this repository when available. Do not publish exploit details or private project data in a public issue. For a public issue about an apparent security problem, describe only that a private reporting channel is needed.

Security-sensitive areas include key storage, project copy detection, extension permissions, local process execution, terminal text sanitization, and the boundary between Calve product state and OpenAEVC authority. Calve must not directly edit OpenAEVC protocol storage.
