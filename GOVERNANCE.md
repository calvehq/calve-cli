# Governance

Calve is maintained through public issues and pull requests. Maintainers review changes for product behavior, tests, documentation, compatibility, and the Calve/OpenAEVC boundary. A maintainer approval is required before merge; security-sensitive changes need a second review when maintainers are available.

Architecture decisions that alter state ownership, a public command contract, or compatibility are recorded under `docs/adr/`. The repository's Git history and release notes are the record of accepted changes. Project governance does not grant Calve authority over OpenAEVC protocol semantics.
