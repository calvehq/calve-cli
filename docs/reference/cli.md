# CLI reference

Generated by `cargo run -p xtask -- cli-reference`; do not edit by hand.

Global flags: `--project <path-or-id>`, `--workspace <name>`, `--as <identity>`, `--config <path>`, `--json`, `--quiet`, `--verbose`, `--no-color`, `--no-daemon-start`, `--direct`, `--endpoint <socket>`.

## `clv materialize`

| Command | Description |
|---|---|
| `clv materialize list` | Journaled materialization operations with their state and unresolved conflicts |
| `clv materialize resume <op>` | Continue an interrupted operation |
| `clv materialize resolve <op> --keep <keep>` | Resolve the operation's conflicts by keeping `ours` (the planned content) or `theirs` (the concurrent writer's bytes), then continue it. Conflict artifacts are kept |
| `clv materialize rollback <op> [--yes]` | Reverse the operation's completed steps, each revalidated first |

## `clv extension`

| Command | Description |
|---|---|

| `clv extension search [<query>]` | Search trusted catalogs |
| `clv extension info <id>` | Show an enabled extension and its manifest |
| `clv extension install <id> [--version <version>] [--catalog <catalog>] [--acknowledge-native]` | Install a package from a trusted catalog (verified, immutable, content-addressed) |
| `clv extension switch-publisher <id> --catalog <catalog> [--yes] [--acknowledge-native]` | Move an id's pinned publisher to another catalog (audited) |
| `clv extension update <id> [--grant <grants>] [--acknowledge-native]` | Install and switch to the newest version (widening needs --grant) |
| `clv extension uninstall <id> [--version <version>] [--yes]` | Remove installed versions that no Project uses |
| `clv extension enable <id> [--grant <grants>] [--acknowledge-native]` | Enable an installed (or installable) extension in this Project |
| `clv extension disable <id>` | Unregister an extension from this Project |
| `clv extension permissions <id>` | Requested versus granted host capabilities |
| `clv extension grant <id> <capabilities>` | Grant requested host capabilities |
| `clv extension revoke <id> <capabilities>` | Revoke host capabilities |
| `clv extension health` | Check enabled extensions |
