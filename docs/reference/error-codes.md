# Error codes

Status: **current** codes are listed as implemented; the **target** taxonomy is implemented in M3 (ADR 0020). Every error is a `Fault{code, message, retryable, detail?}`; OpenAEVC structured errors stay available as nested `detail`.

## Current (implemented)
`UNSUPPORTED_API_VERSION`, `UNSUPPORTED_PAYLOAD_VERSION`, `INVALID_OPERATION_KIND`, `INVALID_CONFIGURATION`, `PROJECT_BUSY`, `PROJECT_OPEN_FAILED`, `PRODUCT_ERROR`, `IO_ERROR`, `DATABASE_ERROR`.

## Target taxonomy (M3)
Product (§41): `PROJECT_NOT_FOUND`, `PROJECT_IDENTITY_CONFLICT`, `PROJECT_LOCKED`, `WORKSPACE_NOT_FOUND`, `INVALID_CONFIGURATION`, `OPENAEVC_INCOMPATIBLE`, `OPENAEVC_OPERATION_REJECTED`, `CAPABILITY_DENIED`, `STALE_VIEW`, `REVIEW_STALE`, `EXTENSION_NOT_INSTALLED`, `EXTENSION_INCOMPATIBLE`, `EXTENSION_PERMISSION_REQUIRED`, `PROVIDER_UNAVAILABLE`, `HARNESS_UNAVAILABLE`, `SECRET_UNAVAILABLE`, `RESOURCE_DIVERGED`, `UNSAFE_MATERIALIZATION`, `DAEMON_UNAVAILABLE`, `DAEMON_INCOMPATIBLE`, `MIGRATION_REQUIRED`, `RECOVERY_REQUIRED`, `CORRUPT_PRODUCT_STATE`, `UNSUPPORTED_PLATFORM_FEATURE`, `USER_CANCELLED`.

Added by rev 10: catalog `CATALOG_STALE`, `EXTENSION_REVOKED`, `EXTENSION_IN_USE`, `PUBLISHER_NOT_AUTHORIZED`, `PACKAGE_INVALID`, `EXTENSION_IDENTITY_MISMATCH` (M2 closeout: the registered manifest differs from the installed one); checks `CHECK_PLAN_UNAPPROVED`, `CHECK_PLAN_CHANGED` (M2 closeout); CIC `INCOMPATIBLE_CIC`, `ABI_VIOLATION`, `TRAPPED`, `OUT_OF_FUEL`, `DEADLINE_EXCEEDED`, `OUT_OF_MEMORY`, `RELATION_FAILED`, `RELATION_REFUSED`, `RELATION_SCHEMA_INVALID`, `CAPTURE_DIVERGED`; capture `CAPTURE_INCOMPLETE`, `FILE_TOO_LARGE`, `SUPERSEDE_CONFLICT`, `SUPERSEDE_DIVERGED`; content `CONTENT_CORRUPT`, `CONTENT_NOT_PORTABLE`, `CLOSURE_UNCLASSIFIED`; materialization `MATERIALIZE_CONFLICT` (`unsafe_fs`, `content_unavailable`, …); containment `CONTAINMENT_UNAVAILABLE`, `HELPER_LOST`; `RecoveryRequired` reasons `trust_state`, `identity_mismatch`, `continuity`, `openaevc_behind`, `journal_corrupt`, `supersede`.
